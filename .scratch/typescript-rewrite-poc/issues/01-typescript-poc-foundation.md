# 01: TypeScript POC foundation

**What to build:** A separately runnable Next.js/TypeScript proof of concept with server-rendered HTML and disposable local SQLite storage, isolated from the Rails application and production configuration.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [ ] The POC starts locally from a clean checkout with documented commands.
